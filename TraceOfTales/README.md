# 📜 Trace Of Tales

**2D 도트 그래픽 내러티브 RPG (졸업작품)**

- **개발 인원**: 6인 팀 프로젝트
- **담당 역할**: 퀘스트 · 대화 · 상점 시스템 설계 및 개발
- **개발 기간**: 2025.02 ~ 2025.11
- **사용 기술**: Unity, C#

> 💡 **안내**
> 이 디렉토리는 팀 프로젝트에서 제가 직접 설계하고 구현한 스크립트만을 발췌한 것입니다. 
> 원본 프로젝트는 팀 소유 비공개 저장소에 있어 전체 공개가 불가능하여, 포트폴리오 리뷰 목적으로 담당 코드만 별도로 정리했습니다. 씬, 에셋, 타 팀원의 스크립트가 포함되어 있지 않아 이 저장소만으로는 단독 실행이 불가합니다.

<br>

## 🎯 핵심 구현 사항

### 1. 다형성(Polymorphism) 기반 퀘스트 아키텍처 설계
- **설계**: `Quest` 추상 클래스를 최상위로 정의하고, 이를 상속받는 5가지 퀘스트 타입(Kill, Collect, Reach, Combined, Dialogue)을 구현하여 결합도를 낮추고 확장성 높은 구조를 확립했습니다.

### 2. 해시(Hash) 기반 퀘스트 이벤트 탐색 최적화
- **이슈**: 이벤트(몬스터 처치, 아이템 획득 등) 발생 시 활성화된 전체 퀘스트 목록을 순회하며 조건을 검사하는 기존 방식의 비효율성 인지.
- **해결**: 몬스터 및 아이템 ID를 Key로 사용하는 `Dictionary` 구조를 도입. 이벤트 발생 시 불필요한 순회 없이 관련된 퀘스트만 즉시 조회하여 처리하도록 탐색 비용을 크게 최적화했습니다.

### 3. 노드 그래프 기반 커스텀 퀘스트 에디터 개발
- **구현**: Unity `EditorWindow`를 확장하여 노드 그래프 형태의 전용 퀘스트 에디터 툴을 직접 제작했습니다.
- **효과**: 퀘스트 간의 복잡한 선행/후속 관계를 시각적으로 확인하고 관리할 수 있게 되어, 기획 파트의 데이터 입력 효율과 팀 전체의 생산성을 크게 향상시켰습니다.

<br>

## 📁 주요 스크립트

| 파일명 | 주요 역할 및 기능 |
| --- | --- |
| `Quest.cs` | 다형성 구현을 위한 퀘스트 최상위 추상 클래스 |
| `QuestManager.cs` | 퀘스트 등록, 이벤트 처리 및 진행 데이터 저장/로드 로직 |
| `DialogueManager.cs` | 시스템 간 연동을 통한 대화 진행 및 퀘스트 상태 갱신 |
| `DialogueChoiceManager.cs` | 퀘스트 진행도 및 조건에 따른 동적 선택지 생성·필터링 |
| `ShopManager.cs` | 상점 내 재화 차감 및 아이템 구매/판매 트랜잭션 처리 |
