# ⛏️ Gentle Miner

**립모션 센서 기반 3D 상지 재활 채굴 게임**

- **개발 인원**: 1인 (기획·개발·최적화 전담)
- **개발 기간**: 2025.07 ~ 2025.08
- **사용 기술**: Unity, C#, Leap Motion SDK, LibreFracture

> 💡 **안내**
> 이 디렉토리는 1인 개발로 진행한 프로젝트의 전체 스크립트를 담고 있습니다. 
> Leap Motion SDK, LibreFracture 등 외부 라이브러리 의존성이 있어 이 저장소의 코드만으로는 독립 실행이 되지 않습니다. 코드 구조와 로직 구현 방식을 확인하는 용도로 참고 부탁드립니다.

<br>

## 🎯 핵심 구현 사항

### 1. 센서 데이터 정밀 보정 (GripCalculator, AimSystem)
- **이슈**: 립모션 기본 API의 악력 측정값이 40~50%의 힘만 가해도 최댓값(1.0)에 조기 포화되는 현상 발견.
- **해결**: 손가락 마디 간 방향 벡터의 내적을 직접 계산하는 커스텀 로직을 구현하여 데이터 측정의 정밀도를 대폭 개선.

### 2. 정확도 기반 타격력 계산 파이프라인
- **설계**: `GripCalculator`/`ForceCalculator` → `AimSystem` → `ToolSystem`으로 이어지는 논리적인 데이터 파이프라인 구축.
- **구현**: 악력, 속도, 양손 협응 정확도를 종합해 최종 타격력을 산출. 이를 LibreFracture 물리 라이브러리와 실시간으로 연동하여 광물의 파괴 범위를 동적으로 조절하도록 구현.

<br>

## 📁 주요 스크립트

| 파일명 | 주요 역할 및 기능 |
| --- | --- |
| `GripCalculator.cs` | 손가락 굽힘 각도 기반 커스텀 악력 계산 로직 |
| `AimSystem.cs` | 양손 협응 정확도 판정 시스템 |
| `ToolSystem.cs` | 최종 타격력 결정 및 실시간 채굴 액션 실행 |
| `HandController.cs` | 립모션 손 데이터 수신 및 타격 감지 인터페이스 |
| `MineralBlock.cs` | 물리 엔진 기반 광물 파괴 및 조각화 로직 |
| `GemProtectionSystem.cs` | 정밀도에 따른 보석 손상도(내구도) 관리 시스템 |
